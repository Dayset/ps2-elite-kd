🪪 Player name checker

Check whether a character name is free — on PC, or on PlayStation's Genudine and Ceres.

Check a name

Character names are unique PC-wide: a name taken anywhere on PC is taken everywhere, on either server. On PlayStation a name can exist on both Genudine and Ceres — even twice on one server — so both are checked.

Names are 3–32 letters and digits, no spaces. That range is measured from the site's own player list (17,497 names); the game's Naming Policy still applies.

Check live again before you create the character: someone can take a name after you check it.
