# PlanetSide 2 hex betting game

Goal ID: goal_4ce5f47123d4
Goal slug: planetside-2-hex-betting-game

## Description
A PlanetSide 2 prediction game where virtual points are staked per map hex — which faction captures it and when — plus a global stake on the alert winner, resolved against ps2alerts.com data. The pool is parimutuel with no house cut; graded entries pay 5%/15%/30% at the 50%/80%/90% checkpoints plus a 10% certainty kicker when model odds exceed 75% (fees feed the winners' pot). The hint system issues 'collapse pattern forming' warnings without directing play. Dayset playtested a past-alert betting simulator and approved the economics; the concept is now being validated with a debute book of opening-15-minute alert archetypes built from hex-flip order, population, and outcomes.
